Privacy Policy

Last updated: 17 November 2026

This policy covers "Clip Watcher", the tool the GTAclips channel uses to make and upload clips, and the GTAclips channel itself.

Use of YouTube API Services

Clip Watcher uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's Privacy Policy applies to data handled by Google.

What data is accessed

Clip Watcher signs in to one Google account only: the account that owns the GTAclips channel. It requests a single permission (youtube.upload) so it can upload videos to that channel. It does not read, collect or store data from any other YouTube user.

How data is stored

The sign-in token is stored only on the channel operator's own computer. It is not sold, shared or sent to any third party, and it is used for nothing except uploading videos to the GTAclips channel.

To find moments worth clipping, the tool reads public Twitch chat anonymously, without logging in. Chat logs stay on the operator's computer and are used only to count messages per few seconds. They are never published.

Cookies

This website and the tool do not use cookies or tracking.

Revoking access

Access can be revoked at any time at Google security settings.

Contact

Send a message to the GTAclips YouTube channel (channel page → About → contact).
